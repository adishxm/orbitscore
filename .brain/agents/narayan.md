# Narayan — frontend and UI lead

## Owns

React/Vite application, typed API client, evidence workflow, confirmation controls, findings dashboard, counterfactual view, human review gate, export screen, and visual polish.

## Working rules

- Build against the API contract and mock fixtures in parallel.
- Always show loading, empty, error, synthetic-data, and limitation states.
- Never display a status that is not returned by deterministic evaluation.
- Keep `CONFLICT`, `NEEDS_EVIDENCE`, and `NOT_EVALUATED` visible in text, not only color.
- Do not add a live orbital map or visual that implies operational tracking.
