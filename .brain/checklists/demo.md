# Demo checklist

The final demo must work with the LLM disabled and with the synthetic fixture already present.

1. Start API and frontend from README commands.
2. Load a synthetic mission.
3. Select a profile.
4. Upload or select the synthetic evidence file.
5. Show candidate fields and human confirmation state.
6. Evaluate deterministic findings.
7. Open a source-linked finding.
8. Show `NEEDS_EVIDENCE` or `CONFLICT`.
9. Run one bounded illustrative counterfactual.
10. Review every finding.
11. Show export locked before review and unlocked after review.
12. Inspect HTML/JSON packet.
13. Verify provenance.
14. State clearly: not official compliance, certification, conjunction assessment, or maneuver advice.

If the network fails, use offline/mock mode and the recorded backup. Never change code live to hide a failure.
