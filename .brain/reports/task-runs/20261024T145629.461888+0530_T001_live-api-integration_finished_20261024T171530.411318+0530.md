## In simple words

Before this task, the React console (`apps/web`) only operated against a local mock evaluation engine running inside the browser's localStorage, while the FastAPI backend (`apps/api`) was running disconnected. This task connects the React frontend directly to the live FastAPI profile evaluation backend over HTTP (`http://localhost:8000`), allowing real mission profiles, rule-driven evaluations, human review decisions, cryptographic provenance verification, and export packet generation to be executed and synchronized with the Python server while preserving an offline mock mode fallback.

## What the team learned

By implementing an explicit contract adapter between the React client and FastAPI server, OrbitScore can seamlessly toggle between zero-latency offline demo mode and full enterprise multi-user API mode. Using standard SHA-256 canonical hashing across both client and server guarantees that human review decisions cannot be forged or tampered with silently.
