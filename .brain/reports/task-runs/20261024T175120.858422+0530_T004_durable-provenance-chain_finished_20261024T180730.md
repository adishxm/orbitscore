## In simple words

Implemented a durable append-only SHA-256 provenance hash chain in SQLite. Every lifecycle event (creation, upload, extraction, confirmation, evaluation, decision, counterfactual, export) is cryptographically linked to the previous event hash. Any manual SQL manipulation or data corruption is immediately detected with the exact sequence number that failed.

## What the team learned

Cryptographic hash chains require strict canonical JSON serialization (sorted keys, compact whitespace separators, UTF-8 encoding) to avoid false-positive tamper detections caused by formatting differences across environments.
