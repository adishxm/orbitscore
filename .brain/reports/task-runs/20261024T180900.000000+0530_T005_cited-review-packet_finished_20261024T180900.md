## What the team learned

Content negotiation via the HTTP `Accept` header and `?format=html` parameter allows the frontend and external compliance auditors to retrieve either machine-readable JSON or print-ready HTML dossiers from the same endpoint.

## Judge questions this unlocks

- What problem does this solve? Prevents incomplete or rubber-stamped compliance exports from leaving the system.
- How did you verify it? Automated tests verify the 423 lock with partial reviews, and unlocking only when every finding is reviewed.
- What is deliberately out of scope? PDF generation binary dependencies; HTML is standard and prints cleanly.
