## In simple words

Built an optional structured LLM extraction adapter with Pydantic schema validation. If AI is disabled (`ORBIT_AI_ENABLED=false`), missing keys, or times out, the system deterministically falls back to regex-based heuristic parsing without error. All candidate fields default to `human_confirmed=False` to prevent unreviewed AI hallucinations from passing compliance rules.
