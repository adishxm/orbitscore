# OrbitScore technical stack — verified package map

## Product boundary

OrbitScore is a source-linked decision-support/pre-review application. The policy catalog contains inspired screening interpretations, not legal determinations, regulator approval, certification, orbital decay models, collision/casualty calculations, conjunction services, or maneuver recommendations. All demonstration mission data are synthetic. The MSRI-style band is a prioritization heuristic and excludes `S_coll` from its calculation.

## Architecture and package map

```text
.
├── frontend/          # Canonical React/Vite/TypeScript web application (Zustand, Lucide, Framer Motion)
├── backend/           # FastAPI service, SQLite persistence, deterministic evaluation, provenance, export
├── ai_ml/             # Isolated AI provider adapter, Pydantic schemas, and standalone unit tests
├── docs/              # Architecture, technical stack, research, and API contract specifications
├── fixtures/          # Synthetic mission inputs, versioned rule profiles, and evaluation verification report
├── research/          # Source library and research indexes

├── .brain/            # Shared agent instructions, tasks, state, and verified run reports
└── legacy/            # Archived initial console (legacy/web) and client library (legacy/frontend-service)
```

## AI Safety Boundary

1. **Deterministic fallback:** AI assistance is disabled by default (`ORBIT_AI_ENABLED=false`). When disabled, or if provider calls fail or time out, the system automatically falls back to the zero-external-dependency regex parser (`backend/app/extractor.py`).
2. **Strictly unconfirmed candidates:** Any field proposed by `ai_ml` is marked `human_confirmed=False` with locator quotes and confidence tiers.
3. **No automated decisions:** The AI adapter never approves evidence, never modifies finding evaluation statuses, and never makes human review decisions.
4. **Controlled execution parameters:** Configured with `temperature=0.0` and a strict `10.0s` timeout.
