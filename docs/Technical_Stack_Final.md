# OrbitScore technical stack — verified package map

## Product boundary

OrbitScore is a source-linked decision-support/pre-review application. The policy catalog contains inspired screening interpretations, not legal determinations, regulator approval, certification, orbital decay models, collision/casualty calculations, conjunction services, or maneuver recommendations. All demonstration mission data are synthetic. The MSRI-style band is a prioritization heuristic and excludes `S_coll` from its calculation.

## Actual backend routes

| Method | Route | Function |
|---|---|---|
| `GET` | `/health` | Health/version response |
| `GET` | `/profiles` | Catalog of selectable policy profiles |
| `GET` | `/missions` | In-process mission list |
| `GET` | `/missions/{mission_id}` | Retrieve a loaded or fixture-backed mission |
| `POST` | `/missions` | Create mission record |
| `POST` | `/missions/{mission_id}/evaluate` | Evaluate selected profile |
| `POST` | `/missions/{mission_id}/findings/{finding_id}/decision` | Save review decision |
| `POST` | `/missions/{mission_id}/counterfactual` | Run illustrative synthetic lever comparison |
| `GET` | `/provenance` | Return event chain and verification result |
| `GET` | `/export/{mission_id}` | Generate cited packet only after every finding has a decision |

FastAPI interactive docs are at `/docs`. The backend demo stores state in memory for the process lifetime. The frontend mock adapter separately persists demo mutations in browser localStorage, with an in-memory fallback for Node tests. Neither storage mechanism is an immutable audit repository.

## Profile boundaries

- `india-dfsm-inspired`: source-linked checklist inspired by ISRO DFSM language, including the >99% PMD probability and <5-year remaining orbital life items, 400±30 km band screen, and trackability/identifiability/maneuverability/passivation evidence. It is not an authoritative interpretation.
- `nasa-std-8719-14c-inspired`: separate configured checks include scoped Req. 4.3-1 planned debris ≥1 mm passing through LEO, Req. 4.4-2 passivation, Req. 4.5-1 collision probability, Req. 4.6 lifetime/reliability, and Req. 4.7-1 casualty expectation. Applicability requires expert confirmation.
- `fcc-22-74-inspired`: only in-scope for the configured demonstration when the orbit is below 2,000 km and the planned mode is uncontrolled atmospheric reentry; the five-year disposal condition is not represented as universal.
- `internal-pre-review`: student/smallsat evidence checklist, not a regulatory profile.

The mock engine and package are deterministic, but simplifications (including scope resolution and evidence selection) are demonstration behavior and require review before real use.
